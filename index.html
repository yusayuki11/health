体重 / BMI 趋势

绿色底带为 BMI 正常范围 18.5–24（中国成人标准 WS/T 428-2013）。触摸或悬停曲线可查看数值。

身体与目标

参考：轻体力活动成年女性每日约 1600–2100 千卡、男性约 1950–2550 千卡（《中国居民膳食营养素参考摄入量》）。减重可在专业指导下适度下调，不建议过低。

每日三大营养素目标

「按热量目标估算」采用常见供能比：蛋白质 20%、脂肪 25%、碳水 55%（1g 蛋白质/碳水 = 4 千卡，1g 脂肪 = 9 千卡），符合《成人肥胖食养指南（2024年版）》推荐范围（蛋白质 15–20%、脂肪 20–30%、碳水 50–60%）。估算后可手动微调；增肌、减脂等特殊需求请咨询专业人士。

千问 AI 接入

如何获取 API Key？
  1. 打开阿里云百炼控制台（bailian.console.aliyun.com）并登录阿里云账号；
  2. 在「API-KEY 管理」中创建一个 API Key，复制 sk- 开头的密钥；
  3. 粘贴到上方输入框并保存。新用户通常有免费额度，具体以控制台为准。

Key 仅保存在当前浏览器本地，估算时直接从浏览器发送给阿里云百炼接口，不经过其他服务器。未配置 Key 时自动使用内置常见食物库估算（离线、参考值）。

数据管理

所有数据仅保存在当前浏览器（localStorage）。换设备或清理浏览器缓存前，请先导出备份。「导出 Excel」生成含体重记录、饮食明细、每日汇总三个工作表的 .xlsx 文件，可用 Excel / WPS 直接打开。

说明

· BMI = 体重(kg) ÷ 身高(m)²，分类依据国家卫生行业标准《成人体重判定》（WS/T 428-2013）：<18.5 偏瘦，18.5–<24 正常，24–<28 超重，≥28 肥胖。适用于 18 岁及以上普通成人，孕妇、儿童青少年、肌肉量极高的运动员不适用。
· 内置食物库热量为每 100 克/毫升参考值折算的常见份量估算；AI 估算同样仅供参考，实际热量受烹饪方式、用油量等影响。
· 本工具用于日常记录参考，不构成医疗建议。
